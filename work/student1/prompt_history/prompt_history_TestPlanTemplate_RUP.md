3.1.3 Тестирование бизнес-циклов (Business Cycle Testing)
Элемент	Содержание
Цель тестирования	Проверить корректность бизнес-процессов BookSphere во времени: покупка, подписка, возврат, пополнение бонусов, обработка заказов, B2B-закупка, маркетплейс.

## 3.1 Виды тестирования (Testing Types)

### 3.1.1 Тестирование целостности данных и БД (Data and Database Integrity Testing)

| Элемент | Содержание |
|---|---|
| **Цель тестирования** | Убедиться, что PostgreSQL, Redis, MongoDB, Elasticsearch, S3 и DRM-хранилище обеспечивают корректный доступ, запись, чтение, кэширование и отсутствие повреждения данных. |
| **Техника** | Проверять доступ к данным без UI: API, SQL, Redis CLI, MongoDB queries, Elasticsearch API. Использовать валидные и невалидные данные. Проверять транзакции заказов, остатки, корзины, сессии, отзывы, прогресс чтения. Проверять миграции, индексы, ограничения, целостность ссылок, синхронизацию между сервисами и кэшем. |

| **Особые условия** | Нужны тестовые БД, приближенные к production по структуре, но не содержащие реальных персональных данных. Для DRM и S3 — тестовые защищённые файлы. **[Предложение]** |

### 3.1.2 Функциональное тестирование (Function Testing)

| Элемент | Содержание |
|---|---|
